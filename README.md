# 경조사 기록장

결혼·장례·돌잔치 같은 경조사에 보낸 돈과 받은 돈을 기록하는 휴대폰 웹앱이에요.
화면은 GitHub Pages에서 열리고, 기록은 내 구글 시트 「경조사 기록장」에 저장돼요.

- 앱 주소: https://friese8807.github.io/gyeongjosa/ (저장소를 만들고 Pages를 켠 뒤)
- 예시 화면: 주소 뒤에 `#demo` 를 붙이면 서버 없이 예시 기록으로 열려요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체(화면·동작). 공통 처리(AppKit)가 안에 들어 있어요 |
| `Code.gs` | 구글 시트에 붙이는 Apps Script 서버 코드 |
| `manifest.webmanifest`, `sw.js` | 홈 화면 앱 설정, 오프라인 캐시 |
| `version.txt` | 새 버전 알림용 숫자. 배포할 때마다 `bump_version.py` 로 올려요 |
| `icon-*-v숫자.png`, `icon.svg` | 홈 화면 아이콘 |

## 처음 연결하기

1. 구글 시트 「경조사 기록장」을 열고 **확장 프로그램 → Apps Script**.
2. `Code.gs` 내용을 붙여 넣고 저장 → 함수 `setup` 을 한 번 실행해 권한을 허용해요(캘린더 권한 포함).
3. **배포 → 새 배포 → 웹 앱**, 실행: 나, 액세스: 모든 사용자 → 배포.
4. 나온 `…/exec` 주소를 앱 **설정 → 구글 시트 백업**에 붙여 넣고 **연결하기**.

## 자주 하는 변경

- 관계·종류·금액 버튼·표시 목록: 앱 **설정 → 항목 관리**에서 바로 고쳐요(시트 「항목」 탭에 저장).
- 기록을 한꺼번에 고치기: 시트 「기록」 탭에서 직접 고쳐도 돼요. id 칸은 비워 두면 앱이 채워요.
- 서버 코드를 고쳤다면: **배포 관리 → 수정 → 새 버전**으로 다시 배포해요(주소는 그대로).
- 화면 코드를 고쳤다면: `python3 scripts/bump_version.py .` 실행 후 GitHub에 올려요. 1~2분 뒤 앱을 다시 열면 새 버전이 떠요.

## 들어 있는 기능

- 내역: 전체·보낸 돈·받은 돈, 합계, 검색, 달별 묶음, 달 고르기, 다가오는 경조사 D-day
- 추가: 보냄/받음, 달력, 이름(이전 기록 자동 안내), 누구의·종류·사이 선택, 금액 빠른 버튼, 표시(#현금 #참석 등), 메모, 연락처
- 상세: 그 사람과 주고받은 기록·합계, 수정·삭제·답례 기록
- 통계: 달별 건수 그래프, 다가오는 일정, 감사 문자 보내기, 해마다·사이별·종류별 합계
- 설정: 구글 시트 백업, 구글 캘린더 일정·전날 알림, 암호 잠금(4자리), 화면 밝기, 항목 관리, CSV 내보내기·불러오기
- 공통: 화면 꽉 채우기, 좌우로 밀어 탭 넘기기, 끌어내려 닫는 시트, 오프라인 대기열, 새 버전 자동 반영, 오류 표시
